⚙ Настройки подключения
  1. platform.deepseek.com → войти (можно через GitHub/Google)
  2. Слева меню → API keys → Create new API key
  3. Скопировать ключ (показывается один раз) и вставить в поле ниже
  4. Пополнить баланс: Top up — цены низкие, обычно доллара достаточно надолго

Официальные цены: api-docs.deepseek.com/quick_start/pricing. У DeepSeek пиковые/непиковые часы — в непиковые (по UTC вне 1:00–4:00 и 6:00–10:00) дешевле. Один из самых дешёвых API среди крупных моделей на рынке.

⚠ Ключ используется только в текущей вкладке браузера. Не вводите ключ на чужом или общем устройстве. Ключ хранится только в памяти страницы и исчезает при перезагрузке — никуда не сохраняется.

Актуальные модели DeepSeek API — deepseek-v4-flash и deepseek-v4-pro. Старые имена deepseek-chat/deepseek-reasoner отключаются 24.07.2026.

https://api.deepseek.com — запросы идут через серверную функцию этой страницы (не напрямую из браузера), ключ никогда не возвращается обратно клиенту.
