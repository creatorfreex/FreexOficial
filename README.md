> Единственная папка Claude, живущая как отдельный git-репозиторий и реально задеплоенная в
> интернет (`origin` → `github.com/creatorfreex/FreexOficial`). Раньше здесь жил прототип
> DeepSeek-чата — история и troubleshooting того модуля сохранены в
> `.agents/Claude/07_REPORTS/2026-07-22_ARCHIVE_deepseek-chat-public-repo-README.md`, не

**Статус:** живой публичный лендинг BEST («Релиз 2», 23.07.2026) — золотой тор + каллиграфический
wordmark в зеркальном хроме, canvas-анимация, тап по слову переключает по кругу все 30
подтверждённых направлений (снимок `TOR_COLORS.json` на момент публикации), под названием —
ссылка на TikTok/YouTube направления, если известна. Внизу статичная надпись «Релиз 2» — не
кнопка, без списка изменений.

## Что внутри

Один файл, `index.html` — статика, без бэкенда, без API-ключей, без серверных функций.
Canvas-анимация кольца + CSS для текста, все цвета/ссылки вписаны прямо в файл (не подгружаются
с сервера) — всё в одном файле намеренно (простой лендинг, не приложение).

## Что сознательно не показано

По прямому решению Создателя (23.07.2026): никакой шестерёнки настроек, никакой кнопки версии/
истории изменений, никакой панели выбора цвета — ничего служебного. Зритель видит только кольцо,
имя, шрифт и ссылку. В приватном Пульте (`control/best-vision.html`) все эти инструменты есть и
никуда не делись — они дальше нужны для работы, просто не в публичной версии.

## Публичный адрес

Тот же Vercel-проект, что раньше показывал DeepSeek-чат — при пуше в `main` передеплоится
автоматически: **https://freex-oficial.vercel.app**

## Источник кода

Живая рабочая/экспериментальная версия с полной историей правок и внутренними комментариями —
`control/best-vision.html` в основном репозитории (`creatorfreex/freex`, приватный). Эта копия —
публичный снимок: без панели настроек, без API вызовов, без внутренних dev-комментариев, цвета и
ссылки на TikTok/YouTube впаяны в файл на момент сборки. Обновляется вручную при следующем
деплое, не автоматически — если в приватной версии добавится/изменится направление или цвет,
здесь это не появится само.
